# Brújula del Solopreneur + laboratorio HTML para Chrome

## Mantener el ADN de tu newsletter
**No renombrarla**, no desautorizar ediciones previas, no convertirla en sección de IA genérica sin ventas. Mantener **jueves** y promesa «una idea útil»; hacerla más inclusiva para quien empieza desde cero. Tu competencia puede tener más experiencia: tu diferenciación es aprender juntos de forma **clara, lenta, respetuosa y práctica**.

## DOS MODOS EDITORIALES intercambiables
| Modalidad | Cuándo | Estructura | CTA |
|---|---|---|---|
| **A. Brújula original** | Hay experiencia/reflexión genuina, pregunta de lectores, historia transparente o decisión editorial | Asunto claro → enseñanza personal → explicación sencilla → acción recomendada → pregunta | Responder el correo o abrir clase |
| **B. Brújula-Lab HTML** | No hay historia original publicable o coincide un tutorial útil | Problema cotidiano → vídeo didáctico → miniaplicación HTML → pasos 1–2–3 → micro-reto → siguiente clase | Descargar HTML y responder con aprendizaje |

**No enviar un HTML solo para llenar espacio**: cada archivo debe resolver una tarea, funcionar localmente y pasar pruebas de facilidad de uso con una persona principiante. Evitar adjuntar ejecutables y macros.

## Entrega de archivos HTML
**Por qué HTML:** permite un mini-laboratorio interactivo sin instalar otra app, siempre que el navegador permita abrir archivos locales. En Chrome escritorio: descargar `.html` desde email/recurso → abrir Descargas → doble clic → navegador abre herramienta. Funciona sin internet cuando no llama APIs. Algunas personas/móviles pueden tener barreras; proporcionar alternativa web/guía ilustrada y explicar que nunca se requiere habilitar macros.

**Captación responsable**:
1. Página pública del vídeo explica el ejercicio antes de pedir email.
2. Formulario GHL solicita como mínimo email; campo opcional `Nivel IA` (Nunca / Poco / Lo uso). Informar finalidades y separar consentimiento de marketing según normativa y región.
3. Enviar enlace de descarga alojado en servicio bajo control y disponible (probar MIME `text/html` o `application/octet-stream` según hosting). No asumir que GHL puede adjuntar HTML en cualquier plan; probar flujo y usar enlace autenticado si procede.
4. Email de bienvenida: pasos para abrir en Chrome, garantía de que el HTML no envía datos, instrucciones de uso, vídeo vinculado y opción alternativa.
5. Etiqueta `HTML_PROMPT_001` a través de clic de enlace o formulario (no fingir que se sabe si realmente completó ejercicio offline).
6. En 3 días preguntar «¿Pudiste usarlo? ¿qué parte costó?»; no exigir capturas con datos de clientes.
7. Jueves siguiente enlazar a segundo tutorial/solución del problema más común.

## Modelo de edición Brújula-Lab (sin escribir newsletter final aquí)
- Asunto: «Tu primer mensaje con IA, sin tecnicismos».
- Apertura: un vendedor necesita responder dudas repetidas y no sabe cómo pedir ayuda a una IA.
- Respuesta del vídeo: aprender a especificar producto, público, tono y tarea.
- Recurso: `01_LABORATORIO_DE_PROMPTS_PARA_VENDER.html` (ejecución Chrome offline).
- 3 instrucciones: escribe producto genérico → selecciona objetivo → copia prompt y pégalo en herramienta que tú elijas.
- Aviso: revisa precios, stock y condiciones antes de usar la respuesta.
- Reto: adaptar una respuesta y contar qué mejoró.
- Regreso: próximo vídeo «ChatGPT o Copilot: misma consulta, distintas respuestas».

## Catálogo de HTML (prioridad por nivel)
1. **Primer prompt para vender** — Nivel 0 — listo en kit.
2. **Calculadora de ganancia real** — Nivel 2, muestra escenarios rotulados — lista en kit, sin usar cifras propias.
3. **Corrector de mensajes** — Nivel 1 — brief: usuario selecciona 3 problemas, genera prompt de revisión sin API.
4. **Checklist de ficha de producto** — Nivel 1 — genera checklist HTML imprimible sin guardar datos.
5. **Comparador de oferta** — Nivel 2 — tabla de beneficios, objeciones y CTA para comparar 2 alternativas.
6. **Agenda de seguimiento** — Nivel 2 — versión offline simple; evitar guardar contactos personales en localStorage compartido.
7. **Análisis de anuncios sin cifras inventadas** — Nivel 3 — CAC y margen con datos del usuario, no promesas.

## Política de producto y seguridad
- HTML sin scripts externos, sin `fetch`, sin rastreo, sin pedir contraseñas ni datos personales, y sin claves de API en frontend.
- Etiquetas claras: «Herramienta didáctica; no genera ventas automáticamente», «ejemplo» o «cálculo orientativo».
- Botones grandes, fuente ≥16px, alto contraste, campos etiquetados, errores visibles; accesible teclado.
- Si GHL o navegador bloquea descarga, no pedir al usuario desactivar seguridad; cambiar hosting o ofrecer página web interactiva normal.

**Guías** son páginas públicas SEO permanentes con ejercicios y procedimiento; **Brújula** es correo jueves, original/reflexivo o Brújula-Lab enlazado al episodio/ejercicio. Guardar archivo público de newsletters con resúmenes originales, sin duplicar íntegramente una guía orientada a la misma búsqueda.
